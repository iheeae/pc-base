# pc-base — развёртывание Windows-ПК одним окном

Развернуть свой ПК с нуля или обслужить чужой: выключить телеметрию, снести мусор, поставить нужные программы.
Одна команда — одно окно со всем каталогом программ и настроек Windows, отмечаешь нужное, жмёшь.
В конце — итог и короткий список того, что доделать руками. Всё обратимое откатывается `undo.ps1`.

Работает на чистой Windows 10 / 11: нужен только встроенный Windows PowerShell 5.1, ничего ставить заранее не надо.

## Запуск

PowerShell **от администратора**:
```powershell
irm iheeae.github.io/pc-base | iex
```
Если на старой Windows 10 ругается на соединение (нет TLS 1.2 по умолчанию):
```powershell
[Net.ServicePointManager]::SecurityProtocol='Tls12'; irm iheeae.github.io/pc-base | iex
```
То же самое прямо из репы, без короткой ссылки:
```powershell
irm https://raw.githubusercontent.com/iheeae/pc-base/master/bootstrap.ps1 | iex
```

Загрузчик (`bootstrap.ps1`) сам поставит winget и Git, склонирует эту репу в `C:\pc-base` и откроет окно.
Входить в GitHub не нужно. Если в `C:\pc-base` лежит старая копия, она переедет в `C:\pc-base.old_<дата>` — ничего не удаляется.

Повторный запуск на уже настроенном ПК (подтянет свежую версию):
```powershell
powershell -ExecutionPolicy Bypass -File C:\pc-base\setup.ps1
```
Ключи: `-Selection <имя или путь>` — открыть окно с сохранением, `-NoPull` — без `git pull`,
`-DataRoot <папка>` — где Мои данные, если не в `C:\pc-base-private`.

Окно стартует в режиме **План**: «Показать план» только показывает, что будет сделано. Боевой прогон — режим
**Применить** и подтверждение.

## Мои данные и сохранения

Движок (эта репа) — общий и безличный. Своё — сохранения галочек, настройки программ, профиль pwsh — живёт в **Моих данных**:
своей приватной репе `<логин>/pc-base-private` на GitHub, клон — в `C:\pc-base-private`.

- **Подключить** — слева внизу в окне: вход в GitHub по одноразовому коду в браузере, репа создаётся приватной, если её нет,
  и клонируется. Всё в фоне, окно не замирает. Сохранения, сделанные до входа, окно предложит перенести.
- **Сохранения ▾** сверху — свои наборы галочек: имя, дата, с какого ПК; открыть, сохранить текущее (Ctrl+S),
  переименовать, удалить. Можно перетащить `.json` на окно. Сохранение — только галочки, настройки программ в нём не лежат.
  С Моими данными каждое изменение — коммит и сразу `push`; нет сети — уйдёт при следующем запуске
  (в окне видно «не отправлено: N»). Без входа сохранения лежат в `%LOCALAPPDATA%\pc-base\saves`.
- **Отключить и стереть с этого ПК** — в меню «⋯» у Моих данных: удаляет `C:\pc-base-private`, выходит из `gh`,
  стирает токен git для github.com. Обслужил чужой ПК — ушёл чистым. На GitHub ничего не удаляется.
- Без входа работает всё, кроме варианта «с моими настройками». Формат данных — [configs/README.md](configs/README.md).

## Окно выбора

Весь каталог в одном окне, всё — галочки, **телеметрия тоже** (группа «Приватность»).
Тема и акцентный цвет — как в Windows (светлая/тёмная).

- **Три колонки.** Слева — разделы «Программы», «Настройки Windows», «Файлы с Диска» и их категории со счётчиком
  «выбрано/всего». В центре — карточки текущей категории, кнопки **Всё / Нет** — для неё.
  Справа — подробности выделенного: полное описание с условиями бесплатности, источник (winget-ID или сайт), что доделать руками.
- **Значки в карточке:** **⚙** — у программы есть вариант «с моими настройками» (залит — выбран, контур — можно включить,
  клик переключает, серый — своих настроек на этом ПК нет); **мастер** — тихо не ставится; **необратимо**;
  **сайт** — качается с официального сайта с проверкой подписи.
- **Установка: с моими настройками / чистая** — блок справа у программ с `ConfigFn`.
  «С моими» сама отмечает программу; снял программу — вариант сбрасывается на чистый; «Всё» его не включает.
- **Поиск** сверху — сразу по всем разделам: название, описание, id, winget-ID, категория.
- **Итог** — внизу слева: всё отмеченное по разделам, галочку можно снять прямо там.
- **Сохранения ▾** — открыть, сохранить, переименовать, удалить свои наборы галочек (см. выше); пункты, которых больше нет
  в каталоге, пропускаются с уведомлением.
- **Файлы с Диска (pc-base-exe)** — список файлов из папки `pc-base-exe` в корне Google Drive; отмеченные копируются
  в «Рабочий стол\pc-base-exe», ничего не ставится.
- **Имя ПК** — пусто = не трогать. В домене вместо поля — текущее имя: переименование требует доменной учётки.
- Пункты **необратимо** (снос UWP, OneDrive) `undo.ps1` не вернёт — только точка восстановления.
- Что не имеет смысла на этой версии Windows, в окне не показывается.
- Клавиши: **Ctrl+F** — поиск, **Esc** — очистить его, **Ctrl+S** — сохранить, **Ctrl+1 / 2 / 3** — разделы, **↑ / ↓** — категории,
  **пробел** — отметить выделенную карточку.

## Порядок прогона
1. Права админа (поднимает сам), `git pull` движка, обмен Моих данных с GitHub
2. Точка восстановления
3. Настройки Windows
4. Программы (winget или официальный сайт с проверкой подписи)
5. Свои настройки программ, где выбрано «с моими настройками»
6. Отмеченные файлы с Google Drive → `Desktop\pc-base-exe`
7. Среда: Windows Terminal, профиль pwsh, `winget upgrade --all`
8. Имя ПК, перезапуск проводника
9. Итоговая таблица, список «доделать руками», предложение перезагрузиться

Логи и журнал изменений — `C:\ProgramData\pc-base\logs\`.

## Как устроен каталог

**Программы:** `catalog/apps.psd1`, одна строка — одна программа, правила в шапке файла.
**Только бесплатное навсегда и без условий** (без лицензий, пробных периодов и ограничений до активации);
исключения — Npcap и Docker Desktop. Источник — winget, а если там нет или старьё — официальный сайт
(`Source = 'web'`: свежая версия со страницы загрузки, без валидной подписи издателя файл не запускается).

**Настройки Windows:** `catalog/tweaks.ps1`. Реестр — только через `Set-Reg`, службы — `Set-SvcStart`,
задачи — `Disable-Task`: тогда изменение попадёт в журнал и откатится.

**Перенос настроек программы:** функция в `lib/configs.ps1` + поля `ConfigFn` / `ConfigFile` / `ConfigName` / `ConfigDesc`
в `apps.psd1`, инструмент снятия — в `tools/`, данные — в своих данных (см. выше).

## Откат
```powershell
powershell -ExecutionPolicy Bypass -File C:\pc-base\undo.ps1
```
Откатывает реестр, службы, задачи и PATH по последнему журналу. Снесённые UWP и поставленные программы
не возвращаются: для них есть точка восстановления, которую скрипт делает в начале.

## Файлы
```
bootstrap.ps1          загрузчик для чистой системы, только ASCII (публикуется на Pages)
setup.ps1              главный скрипт: окно выбора, прогон
undo.ps1               откат по журналу изменений
catalog/apps.psd1      программы
catalog/tweaks.ps1     настройки Windows
configs/               встроенные настройки по умолчанию и формат своих
tools/                 снятие настроек программ с настроенного ПК
lib/common.ps1         реестр/службы/задачи с журналом, winget, установка с сайта, поиск конфигов
lib/data.ps1           сохранения и Мои данные: git, вход в GitHub, отключение со стиранием
lib/configs.ps1        перенос настроек программ
lib/gui.ps1            окно выбора и окошко файлов (WPF)
lib/ui/                разметка окон (*.xaml), стили (theme.xaml), модель для привязок (model.cs)
.github/workflows/     публикация загрузчика на GitHub Pages
```
Все `.ps1` / `.psd1` / `.xaml` / `.cs`, кроме `bootstrap.ps1`, — **UTF-8 с BOM**: без него Windows PowerShell 5.1
ломает кириллицу.
