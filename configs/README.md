# configs — настройки по умолчанию и формат своих

Здесь лежит только встроенное и безличное: `pwsh_profile.ps1` — профиль PowerShell 7 по умолчанию.

Свои настройки программ живут **не здесь**, а в своих данных — отдельной (обычно приватной) репе,
склонированной в `C:\pc-base-private` (другой путь — `setup.ps1 -DataRoot <папка>`). Структура та же:

```
C:\pc-base-private\
  configs\
    pwsh_profile.ps1        свой профиль pwsh — перекрывает встроенный
    vivaldi\prefs.json      настройки Vivaldi для варианта «с моими настройками»
  selections\*.json         сохранённые наборы галочек
```

pc-base ищет каждый файл сначала в своих данных, потом здесь. Нет ни там, ни там — вариант
«с моими настройками» в окне недоступен (с подсказкой), прогон при этом не падает.

## Как снять свои настройки
- **Vivaldi:** на настроенном ПК `powershell -ExecutionPolicy Bypass -File C:\pc-base\tools\export-vivaldi.ps1`.
  Берётся только поддерево `vivaldi` из `Preferences` (интерфейс, панели, вкладки, поведение); всё похожее на аккаунты,
  почту, синхронизацию, токены и пароли вырезается, расширения не трогаются. Файл ложится в
  `C:\pc-base-private\configs\vivaldi\prefs.json`, если своя папка есть, иначе рядом со скриптом.
  Перед коммитом — просмотреть глазами.

## Как добавить программу с переносом настроек
Функция в `lib/configs.ps1` + поля `ConfigFn`, `ConfigFile`, `ConfigName`, `ConfigDesc` в `catalog/apps.psd1`,
инструмент снятия — в `tools/`. Секреты (пароли, токены, ключи, учётки) не должны попадать в снимок никогда.
